زیر میکروسکوپ: یک InterfaceTOOL DEFINITION

"name" — مدل با همین نام ابزار را صدا می‌زند.

"description" — مدل این را می‌خواند تا بفهمد این ابزار چی‌ست و کِی به کار می‌آید.

"parameters" — ورودی‌هایی که باید بدهد؛ همین قرارداد، رابطِ مدل با دنیای بیرون است.

{
  "name": "read_file",
  "description":
    "Read a file from the workspace",
  "parameters": {
    "path": "string"
  }
}

هر ابزار = یک قرارداد: نام + توضیح + ورودی — MCP همین قراردادها را استاندارد می‌کند.
